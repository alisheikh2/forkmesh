## What is ForkMesh?

ForkMesh is an open-source federated Git platform built for developers and open-source communities.

Instead of trusting a single hosting provider, ForkMesh lets repositories live across a network of desktop nodes. Your code, issues, pull requests, releases, AI agents, and collaboration stay portable and resilient.

If one node disappears, another can continue serving the repository.

No vendor lock-in.

No single point of failure.

Just Git.

---

## Features

- Federated Git hosting
- Repository mirroring & failover
- Issues & Pull Requests
- AI Coding Agents (Claude Code & Codex)
- Built-in Actions
- End-to-end encrypted repository chat
- Solana bounties
- Flutter mobile app
- IDE Extension
- Developer profiles
- Repository browser
- Signed identities
- Cloudflare-powered edge infrastructure
